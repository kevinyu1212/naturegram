# MVP Acceptance Criteria

## Observation

- 사용자는 로그인 후 관찰을 생성할 수 있다.
- 최소 1개의 미디어 또는 관찰 설명이 있어야 한다.
- 관찰 시각을 저장한다.
- 위치를 저장하거나 위치 비공개를 선택할 수 있다.
- 관찰자는 자신의 관찰을 수정/삭제할 수 있다.
- 타인의 관찰을 임의로 수정/삭제할 수 없다.

## Map

- 지도 viewport 안의 관찰을 조회할 수 있다.
- 다수의 점은 cluster 처리한다.
- 민감 위치는 공개 위치 정책을 적용한다.

## Identification

- 사용자는 다른 분류군에 대한 식별 의견을 제출할 수 있다.
- 식별 의견은 작성자와 시간을 기록한다.
- 현재 식별과 의견 이력을 분리한다.

## Security

- 인증 없는 사용자는 보호된 API에 접근할 수 없다.
- resource owner 검증을 서버에서 수행한다.
- 업로드 파일 타입/크기를 검증한다.
