# Development Environment

- Windows 11
- Git
- GitHub
- VS Code
- Java 21 LTS
- Node.js LTS
- Python 3.11+
- Docker Desktop
- PostgreSQL 16+
- PostGIS
- DBeaver 또는 pgAdmin
