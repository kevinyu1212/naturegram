# Naturegram Product Vision

## 1. 제품 정의

Naturegram은 자연관찰 기록을 소셜 콘텐츠로만 소비하지 않고, 구조화된 `Observation` 데이터로 축적하여 시민과학과 생물다양성 연구에 활용할 수 있게 하는 플랫폼이다.

## 2. 문제

기존 자연관찰 서비스는 각각 강점이 있지만 다음 문제가 남는다.

1. 초보자가 정확한 생물 식별에 접근하기 어렵다.
2. 관찰 데이터와 일반 SNS 콘텐츠가 섞이면 연구용 데이터 품질 관리가 어렵다.
3. 시민이 어디에서 무엇을 관찰하면 과학적으로 가치가 있는지 알기 어렵다.
4. AI 식별 결과와 과학적 확정/검증 결과가 혼동될 수 있다.
5. 연구자에게 필요한 데이터 수집 프로젝트와 시민 참여를 연결하는 과정이 복잡하다.
6. 희귀종·보호종의 위치정보를 공개할 때 보호와 활용 사이의 정책이 필요하다.

## 3. 해결책

Naturegram은 다음 파이프라인을 핵심 제품 경험으로 삼는다.

`Observe → Assist → Verify → Qualify → Analyze → Act`

- Observe: 사진/영상/소리/위치/시간/환경을 기록
- Assist: AI가 분류군과 종 후보를 제시
- Verify: 사용자·커뮤니티·전문가가 식별 의견을 추가
- Qualify: 데이터 완전성·식별 합의·위치 품질 등을 별도로 평가
- Analyze: 지도·시계열·분포·데이터 공백을 탐색
- Act: 시민과학 미션·연구 프로젝트·교육·보전 활동으로 연결

## 4. 핵심 원칙

- Observation과 Post를 분리한다.
- AI 예측과 과학적 검증을 분리한다.
- 품질은 단일 점수보다 여러 차원으로 표현한다.
- 민감한 위치는 공개 수준을 별도로 제어한다.
- 시민의 입력 부담은 최소화하고 시스템이 가능한 정보를 자동 채운다.
- 연구자에게 재사용 가능한 표준 데이터와 API를 제공한다.
- 데이터 삭제/수정/라이선스/감사 이력을 추적한다.

## 5. 비전

한국에서 시작해 동아시아 생물다양성 시민과학 데이터 인프라로 확장한다.

## 6. 성공 정의

초기:
- 관찰 등록이 쉽다.
- AI가 식별 보조를 한다.
- 커뮤니티가 검증할 수 있다.

중기:
- 연구 프로젝트가 시민에게 데이터 수집을 요청할 수 있다.
- 지도에서 시간·공간·분류군별 패턴을 분석할 수 있다.

장기:
- 재현 가능한 연구 데이터셋과 공개 API를 제공한다.
- 시민과학 데이터가 실제 연구·교육·보전 프로젝트에 재사용된다.
