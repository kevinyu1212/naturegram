# Product Requirements Document

## 1. MVP 목표

MVP의 목표는 다음 한 문장을 만족하는 것이다.

> 사용자가 자연에서 발견한 생물을 빠르게 기록하고, 다른 사용자가 그 기록을 확인할 수 있다.

## 2. MVP 포함 범위

### 계정
- 회원가입
- 로그인/로그아웃
- 프로필
- 기본 권한

### 관찰
- 사진 업로드
- 관찰 날짜/시간
- 위치
- 관찰자
- 종/분류군 추정값
- 설명
- 관찰 공개 범위
- 관찰 수정/삭제

### 탐색
- 관찰 피드
- 종 검색
- 지도
- 지역/날짜/분류군 필터
- 관찰 상세

### 커뮤니티
- 식별 의견 추가
- 댓글
- 좋아요/즐겨찾기
- 신고

### 운영
- 관리자
- 신고 처리
- 기본 감사 로그

## 3. MVP 제외

- 자체 AI 모델 학습 플랫폼
- 실시간 전문가 매칭
- 고급 연구 통계
- 유료 구독
- 복잡한 모바일 앱
- 대규모 분산 시스템
- 자동 정책 의사결정

## 4. Phase 2

- AI 종 식별
- 유사종 비교
- 추가 사진 요청
- 관찰 품질 평가
- 시민과학 프로젝트
- 미션
- 개인 생물종 목록
- 알림

## 5. Phase 3

- 전문가 검증
- 데이터 공백 지도
- 연구자 대시보드
- CSV/GeoJSON/Darwin Core export
- 공개 API
- 연구 프로젝트

## 6. Phase 4

- 소리 기반 식별
- 영상 기반 관찰
- 환경 센서 데이터
- 종 분포 예측
- 장기 생태 시계열
- 기관/학교용 프로젝트 관리

## 7. 제품 원칙

기능을 늘리는 것보다 `Observation` 데이터의 품질과 재사용성을 우선한다.
