# Competitive / Reference Notes

## iNaturalist

iNaturalist의 공식 API 문서에서는 observation이 핵심 엔드포인트이며 JSON/CSV/Darwin Core 등의 형태로 데이터를 조회할 수 있고, 위치/시간/분류군/프로젝트 등으로 필터링할 수 있다. 공식 개발자 문서는 새 API 사용을 권장하며 API 사용량 제한도 안내한다.

Naturegram이 배울 점:
- Observation 중심 모델
- 커뮤니티 식별
- Project
- 공개 API
- 연구 데이터 export

차별화 방향:
- AI를 식별 버튼이 아니라 증거 수집 보조로 사용
- 데이터 품질을 다차원으로 표현
- 데이터 공백 기반 시민과학
- 한국/동아시아 생물다양성 워크플로에 특화

## Natureing

네이처링은 자연관찰, 미션, 생태지도, 아카이빙을 중심으로 한 국내 시민과학/자연관찰 서비스로 참고한다.

Naturegram이 배울 점:
- 한국 사용자에게 익숙한 자연관찰 경험
- 미션/프로젝트 기반 참여
- 생태지도

차별화 방향:
- AI 식별/추가 증거 요청
- 연구자용 데이터셋
- 표준화된 Observation
- 품질/검증/provenance

## 주의

경쟁 서비스의 UI/문구/브랜드를 복제하지 않는다. 기능적 아이디어를 참고하되 독자적인 정보구조, UX, 데이터 모델, 브랜드를 설계한다.
