# User Flows

## A. 첫 관찰

방문 → 관찰하기 → 사진 선택 → 위치 확인 → AI 후보 → 관찰 저장 → 상세 페이지

## B. AI 식별 보조

사진 → 품질 검사 → 후보 생성 → 후보 3~5개 → 유사종 설명 → 사용자가 선택/보류 → 식별 의견 기록

## C. 커뮤니티 검증

관찰 발견 → 식별 요청 → 다른 사용자 식별 → 의견 누적 → 합의/불일치 → 전문가 검토 필요 여부 결정

## D. 시민과학 프로젝트

프로젝트 탐색 → 프로젝트 설명 → 목표/지역/기간 확인 → 참여 → 관찰 등록 → 프로젝트 통계 반영

## E. 데이터 공백 탐색

지도 → 데이터 공백 레이어 → 관심 지역 선택 → 부족한 분류군 확인 → 관찰 계획 → 관찰 등록

## F. 연구자

프로젝트 생성 → 연구 질문 → 필요한 필드 정의 → 모집 → 데이터 수집 → 품질 검토 → 분석 → export
